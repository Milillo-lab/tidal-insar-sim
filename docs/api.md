# API reference

Curated guide to the public Python API. See the
[full autogenerated docstrings](#curated-vs-autogenerated) at the bottom.

## Top-level

```python
from tidal_insar_sim import Sensor, Site, Simulator, TripletReport
```

## `Sensor`

`@dataclass(frozen=True)`. Immutable SAR sensor descriptor.

| Field           | Type   | Notes                             |
|-----------------|--------|-----------------------------------|
| `name`          | `str`  | Display name.                     |
| `wavelength_m`  | `float`| SAR wavelength (m).               |
| `repeat_days`   | `float`| Nominal repeat interval.          |
| `incidence_deg` | `float`| Centre incidence angle.           |
| `polarization`  | `str`  | Default "HH".                     |
| `provider`      | `str`  | Agency / operator.                |

**Presets** (class attributes):

```python
Sensor.NISAR_L             # 23.6 cm, 12 d, 39 deg
Sensor.SENTINEL_1_SINGLE   # 5.56 cm, 12 d, 39 deg (post S1B)
Sensor.SENTINEL_1_DUAL     # 5.56 cm,  6 d, 39 deg (pre  S1B)
Sensor.ALOS_2              # 23.6 cm, 14 d, 34 deg
Sensor.ALOS_4              # 23.6 cm, 14 d, 34 deg
Sensor.COSMO_SKYMED        # 3.12 cm,  4 d, 32 deg
Sensor.TERRASAR_X          # 3.11 cm, 11 d, 36 deg
Sensor.RADARSAT_CONSTELLATION  # 5.56 cm,  4 d, 34 deg
Sensor.UMBRA_X             # 3.12 cm,  0 d (tasked), 40 deg
```

**Properties:** `half_wavelength_m`, `fringe_los_cm`.

## `Site`

Grounding-zone site with ice-mechanical parameters.

| Field              | Default  | Notes                          |
|--------------------|----------|--------------------------------|
| `lat, lon`         | —        | WGS-84 (lat < 0 for v0.1).     |
| `name`             | —        | Short identifier.              |
| `ice_thickness_m`  | 400.0    | H in the flexure formula.      |
| `young_modulus_pa` | 0.88e9   | E.                             |
| `poisson_ratio`    | 0.30     | ν.                             |
| `rho_water`        | 1028.0   | Seawater density.              |

**Presets** (Antarctic only in v0.1):

`Site.THWAITES`, `Site.PIG`, `Site.RUTFORD`, `Site.ROSS_GZ16`,
`Site.TOTTEN`, `Site.POPE`, `Site.SMITH`, `Site.KOHLER`.

**Methods:**

- `Site.from_coords(lat, lon, name=None, ice_thickness_m=400, ...)`
- `site.flexural_parameter_beta() -> float`
- `site.limit_of_flexure_m() -> float`

## `Simulator`

Binds a `Sensor`, a `Site`, and a tide function.

```python
sim = Simulator(sensor=Sensor.NISAR_L, site=Site.THWAITES)
# tide_fn defaults to CATS2008 auto-load;
# pass tide_fn=my_mock for deterministic tests.
```

**Methods:**

- `sim.sweep_triplets(step_hours=1.0, duration_days=29.53) -> TripletReport`
- `sim.synthesize_ddinsar(triplet_start_hours, *, size_m, pixel_m, gamma_grounded, gamma_shelf, multi_look, noise_seed) -> FringeMap`
- `sim.confidence(triplet_start_hours, *, jitter_hours=1.0, n_realisations=10_000, rng=None, min_fringes_threshold=1.0) -> float`

## `TripletReport`

Output of `sweep_triplets`. Bound to its originating `Simulator` so it can
call the planner lazily.

**Quick accessors:**

- `report.fringes` — `ndarray[float64]` per triplet.
- `report.h_dd_m` — DD vertical-displacement scalar per triplet.
- `report.delta_t_hours` — triplet start offsets, hours from epoch.
- `report.best_triplet_h()`, `report.worst_triplet_h()`.

**Aggregates:**

- `report.summary() -> dict[str, Any]` — JSON-ready stats + verdict.
- `report.class_fractions() -> dict[str, float]` — NULL / WEAK / MARGINAL / GOOD / STRONG / PEAK.
- `report.p_at_least(n)`, `report.p_below(n)`.

**Exports:**

- `report.to_csv(path)`
- `report.to_geojson(path, include_polygon=True)`
- `report.to_kml(path, include_polygon=True)`
- `report.recommended_triplets(start_date, end_date, n=10, min_fringes=3.0) -> pandas.DataFrame`

## `FringeMap`

Returned by `Simulator.synthesize_ddinsar`.

- `.array` — `complex64[H, W]` field.
- `.wrapped_phase`, `.coherence`, `.h_dd_field_m` — float64 views.
- `.transform` — GDAL affine (6-tuple).
- `.crs_epsg` — 3031 (Antarctic).
- `.to_geotiff(path)` — 3-band LZW-compressed.
- `.to_png(path, cmap="hsv")`.

## Tide backends

`from tidal_insar_sim.tides import CATSBackend, MixedTide, ...`

- `CATSBackend(data_dir=..., extrapolate_cutoff_km=10.0)` — production tide
  source; loads from `~/.tidal_insar_sim/tides/CATS2008/` by default.
  Methods: `extract_constants(lat, lon)`, `predict_tide_m(lat, lon, delta_time_s)`.
- `mixed_m2_k1_tide()` — deterministic M2+K1 mock (prototype-matching).
- `multi_constituent_tide(amplitudes_m, phases_deg)` — arbitrary-constituent mock.
- Errors: `TidalDataUnavailable`, `OutsideDomain`, `OnLand`.

## Planner

```python
from tidal_insar_sim.planner import plan_acquisitions, to_ics
```

- `plan_acquisitions(sim, start_date, end_date, n=10, min_fringes=3.0, ...) -> pandas.DataFrame`
- `to_ics(plan_df, path)` — writes a Google/Outlook-importable calendar.

## Batch

```python
from tidal_insar_sim.batch import batch_compare, pivot_heatmap, batch_to_parquet
```

- `batch_compare(sites, sensors, *, tide_fn_factory=None) -> pandas.DataFrame`
- `pivot_heatmap(df, metric="P_usable_ge_3fr")` — long → wide pivot.
- `batch_to_parquet(df, path)`, `batch_from_parquet(path)`.
